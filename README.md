# Santa Cruz Evolve

Quiero desarrollar una landing page premium, minimalista y altamente cuidada para un proyecto llamado:

SANTA CRUZ SOSTENIBLE

La portada debe inspirarse conceptualmente en la calidad de experiencia de:

https://www.apple.com/

y

https://prometheusfuels.ai/

No copiar diseños, código, imágenes, textos ni identidad visual.

Quiero tomar únicamente como referencia sus principios de diseño:

simplicidad

jerarquía visual

tipografía grande

imágenes protagonistas

mucho espacio

mensajes cortos

navegación minimalista

animaciones elegantes

transiciones fluidas

sensación premium

excelente rendimiento

storytelling visual

OBJETIVO

Crear una portada que sea:

simple, elegante, moderna, memorable y muy bien desarrollada.

No quiero una página llena de información.

La primera pantalla debe transmitir únicamente una idea:

SANTA CRUZ SOSTENIBLE

Debe sentirse como una visión de futuro para la ciudad.

HERO

El Hero debe ocupar prácticamente todo el viewport.

Utilizar una fotografía o video cinematográfico relacionado con Santa Cruz de la Sierra, preferentemente mostrando:

ciudad

áreas verdes

espacios públicos

árboles

arquitectura

personas

La imagen debe ser el elemento visual protagonista.

Sobre ella:

SANTA CRUZ

SOSTENIBLE

Debajo:

Una ciudad que evoluciona.

Y debajo un único botón:

DESCUBRIR

No agregar más botones.

No agregar tarjetas.

No agregar estadísticas.

No agregar mapa.

No agregar formularios.

No agregar selector de distritos.

No mostrar información administrativa.

NAVBAR

Crear una navegación extremadamente minimalista.

Izquierda:

SANTA CRUZ SOSTENIBLE

Derecha:

DESCUBRIR

Puede utilizarse una navegación transparente sobre el Hero.

Debe desaparecer o transformarse elegantemente al hacer scroll.

BOTÓN DESCUBRIR

El botón debe ser visualmente sencillo pero tener una microinteracción elegante.

Al pasar el mouse:

cambio suave

pequeño desplazamiento

transición de fondo

interacción sutil

No utilizar efectos exagerados.

Al hacer clic:

iniciar una transición suave hacia la siguiente sección.

TRANSICIÓN

La transición entre Hero y segunda sección debe ser una de las partes más cuidadas de la página.

Puede utilizar:

fade

zoom

desplazamiento

cambio gradual de imagen

transformación de escala

La transición debe sentirse natural y cinematográfica.

No utilizar efectos excesivos.

SEGUNDA SECCIÓN

Después del Hero mostrar:

UNA CIUDAD.

UN FUTURO.

Texto corto:

Santa Cruz tiene la oportunidad de construir una ciudad más sostenible, conectando personas, empresas y espacios públicos.

Después de esta sección comenzará posteriormente el desarrollo del proyecto.

IDENTIDAD VISUAL

No utilizar únicamente verde.

La paleta debe estar inspirada en sostenibilidad pero con una estética premium:

verde profundo

negro

blanco

tonos naturales

gris neutro

El verde debe ser un acento, no dominar toda la interfaz.

Evitar el aspecto típico de:

“página ecológica”.

Debe sentirse más cercano a:

tecnología + ciudad + naturaleza + futuro.

TIPOGRAFÍA

Utilizar una tipografía moderna y elegante.

Los titulares deben ser grandes.

Ejemplo:

SANTA CRUZ

SOSTENIBLE

Utilizar mucho espacio alrededor del texto.

No colocar párrafos largos.

ANIMACIONES

Usar animaciones únicamente cuando mejoren la experiencia.

Ejemplos:

aparición suave del título

aparición escalonada del subtítulo

transición elegante del botón

movimiento muy ligero del fondo

scroll cinematográfico

Evitar:

partículas excesivas

objetos flotando por toda la pantalla

animaciones constantes

efectos 3D innecesarios

transiciones demasiado llamativas

La sensación debe ser:

precisión, no espectáculo.

RESPONSIVE

La experiencia debe estar perfectamente optimizada para:

Desktop

Laptop

Tablet

Smartphone

En móvil el Hero debe mantener el impacto visual.

La tipografía debe adaptarse correctamente.

La navegación debe convertirse en un menú minimalista.

TECNOLOGÍA

Preferentemente utilizar:

Next.js

React

TypeScript

Tailwind CSS

Framer Motion

La implementación debe priorizar:

rendimiento

accesibilidad

SEO

responsive

código limpio

componentes reutilizables

imágenes optimizadas

carga rápida

No utilizar una librería pesada solamente para agregar efectos.

PRINCIPIO DE DISEÑO

Seguir esta regla:

MENOS ELEMENTOS.

MEJOR DISEÑO.

No intentar llenar la pantalla.

El espacio vacío es parte del diseño.

Cada elemento debe tener una razón para existir.

RESULTADO ESPERADO

Cuando una persona abra la página quiero que durante los primeros segundos vea solamente:

SANTA CRUZ SOSTENIBLE

Una ciudad que evoluciona.

[ DESCUBRIR ]

y una imagen/video impresionante de Santa Cruz.

La sensación final debe ser:

“Esto está muy bien hecho.”

Debe parecer una experiencia digital moderna y profesional, no una plantilla.

El proyecto crecerá posteriormente con mapas, áreas públicas, adopciones, empresas, convenios y otros módulos.

Pero por ahora desarrollar únicamente esta landing page inicial.    ACTUALIZACIÓN DE DISEÑO — SANTA CRUZ SOSTENIBLE

Quiero modificar la propuesta visual de la portada de:

SANTA CRUZ SOSTENIBLE

La nueva dirección visual debe ser mucho más representativa de Santa Cruz de la Sierra, manteniendo una experiencia moderna, premium, limpia y tecnológica.

Las referencias de calidad y experiencia siguen siendo:

https://www.apple.com/

https://prometheusfuels.ai/

https://activetheory.net/

No copiar sus diseños. Tomar únicamente inspiración de su nivel de ejecución, composición, narrativa, tipografía, animaciones y experiencia de usuario.

1. NUEVA PALETA DE COLORES

Quiero abandonar la paleta oscura/anterior y utilizar una identidad basada principalmente en:

BLANCO + VERDE

El blanco debe ser el color predominante de la interfaz.

El verde debe ser el elemento que represente la identidad de Santa Cruz y la sostenibilidad.

Proponer una paleta elegante como:

Verde principal: verde profundo y sofisticado.

Verde secundario: verde natural ligeramente más luminoso.

Blanco: predominante para fondos y espacios.

Gris muy claro: únicamente para separar secciones o elementos.

Evitar:

negro dominante

marrón dominante

demasiados colores

degradados excesivos

aspecto de página ecológica genérica

La sensación debe ser:

frescura + naturaleza + ciudad + elegancia.

2. IDENTIDAD CRUCEÑA

Quiero que la página tenga elementos visuales que hagan sentir inmediatamente que estamos hablando de:

SANTA CRUZ DE LA SIERRA

Pero de una forma moderna y elegante.

NO quiero llenar la interfaz de símbolos folclóricos.

La identidad debe aparecer mediante:

NATURALEZA

Vegetación tropical, árboles, palmeras, jardines y áreas verdes características de Santa Cruz.

CIUDAD

Calles, plazas, arquitectura, espacios urbanos y vida cotidiana.

ESPACIOS PÚBLICOS

Plazas, alamedas, parques y lugares que la gente realmente reconoce.

LUZ Y CLIMA

Transmitir visualmente el carácter cálido, luminoso y tropical de Santa Cruz.

3. ESTÉTICA CRUCEÑA CONTEMPORÁNEA

No quiero una estética turística tradicional.

No quiero que parezca:

una página de turismo

una página folclórica

una campaña política

una web municipal antigua

Quiero crear algo que podría describirse como:

“Santa Cruz del futuro.”

Una combinación de:

identidad cruceña + sostenibilidad + tecnología + diseño premium.

4. HERO

Mantener el Hero a pantalla completa.

Fondo preferentemente:

una fotografía o video cinematográfico REAL de Santa Cruz de la Sierra.

La escena podría mostrar:

una plaza

una avenida arbolada

una combinación de ciudad y naturaleza

un área pública

arquitectura urbana con vegetación

Aplicar una composición limpia.

En el centro:

SANTA CRUZ

SOSTENIBLE

Subtítulo:

Una ciudad que evoluciona.

Botón principal:

DESCUBRIR

5. BLANCO COMO ELEMENTO DOMINANTE

Quiero que después del Hero aparezcan grandes bloques blancos.

Por ejemplo:

Hero:
fotografía + verde

↓

Sección blanca:

UNA CIUDAD.

UN FUTURO.

↓

Sección verde:

fotografía + contenido

↓

Sección blanca:

ESPACIOS QUE TRANSFORMAN.

Esto debe generar mucho contraste visual.

6. ELEMENTOS GRÁFICOS

Crear algunos elementos propios inspirados sutilmente en Santa Cruz.

Por ejemplo:

líneas curvas inspiradas en formas orgánicas

patrones muy discretos

formas geométricas inspiradas en arquitectura local

elementos gráficos inspirados en hojas tropicales

formas circulares o curvas que evoquen plazas y espacios urbanos

Estos elementos deben ser minimalistas.

No llenar la página de hojas.

7. REFERENCIA A LA IDENTIDAD VERDE CRUCEÑA

El verde debe aparecer de forma estratégica:

botones

títulos destacados

fondos completos de algunas secciones

pequeños detalles

indicadores

hover

líneas

iconos

No utilizar verde en absolutamente todo.

La combinación predominante debe ser:

blanco + verde + fotografía.

8. SEGUNDA SECCIÓN

Después del Hero:

Fondo blanco.

Título enorme:

UNA CIUDAD.

UN FUTURO.

Texto:

Santa Cruz tiene la oportunidad de crecer de una manera diferente: cuidando sus espacios públicos, fortaleciendo sus áreas verdes y construyendo una ciudad más sostenible.

Agregar una pequeña línea gráfica verde.

9. SECCIÓN “SANTA CRUZ”

Crear una sección visual donde Santa Cruz sea protagonista.

Título:

NUESTRA CIUDAD.

Mostrar una fotografía/video grande.

Sobre la imagen, pequeños textos:

ESPACIOS

NATURALEZA

COMUNIDAD

FUTURO

La sección debe transmitir que la sostenibilidad comienza en la propia ciudad.

10. SECCIÓN DE ADOPCIÓN

Texto blanco:

ADOPTA.

CUIDA.

TRANSFORMA.

Texto:

Empresas e instituciones pueden convertirse en aliados de Santa Cruz y contribuir a la recuperación y cuidado de nuestros espacios públicos.

Botón blanco:

CONOCE EL PROGRAMA

Esta debe ser una de las secciones visualmente más fuertes.

11. SECCIÓN DE ESPACIOS PÚBLICOS

Mostrar imágenes grandes y reales de:

plazas

alamedas

parques

áreas verdes

No mostrar las imágenes como pequeñas tarjetas genéricas.

Podrían ocupar gran parte de la pantalla.

Texto:

ESPACIOS

QUE NOS PERTENECEN A TODOS.

12. MAPA

Mantener el mapa como una sección secundaria.

No mostrarlo en el Hero.

Más adelante:

DESCUBRE LOS ESPACIOS.

Mostrar un mapa visual de Santa Cruz.

Posteriormente se conectará con Google Maps.

El mapa real podrá mostrar las áreas públicas disponibles para adopción.

13. IMPACTO

Crear una sección limpia con estadísticas.

Usar verde sobre blanco.

Ejemplo:

ÁREAS PÚBLICAS

EMPRESAS

ESPACIOS RECUPERADOS

IMPACTO

Los valores deben quedar preparados para ser reemplazados con datos reales.

14. NAVBAR

La navegación debe ser muy simple.

Logo/texto:

SANTA CRUZ SOSTENIBLE

Menú:

ESPACIOS

ADOPTA

IMPACTO

DESCUBRIR

Utilizar una versión blanca o transparente sobre imágenes.

Cuando el usuario entra a secciones blancas, la navegación puede transformarse a verde.

Esta transición debe ser suave.

15. BOTONES

Los botones deben tener una identidad visual propia.

Principal:

Fondo verde
Texto blanco

Hover:

transición suave hacia un verde diferente.

Botón secundario:

Fondo blanco
Texto verde
Borde verde.

Evitar botones gigantes o demasiado redondeados.

Buscar un estilo elegante y contemporáneo.

16. TIPOGRAFÍA

Los titulares deben ser grandes y contundentes.

Ejemplo:

SANTA CRUZ

SOSTENIBLE

Usar una tipografía moderna, limpia y sofisticada.

Mucho espacio alrededor de los titulares.

No utilizar demasiados estilos de fuente.

17. ANIMACIONES

Mantener las animaciones elegantes:

fade

desplazamiento

parallax

zoom suave

cambios de escala

aparición progresiva

transiciones entre blanco y verde

Las animaciones deben ser lentas y suaves.

La sensación debe ser:

premium y natural.

18. FOTOGRAFÍA

Esto es muy importante.

Priorizar fotografías reales de:

Santa Cruz de la Sierra.

No utilizar únicamente imágenes genéricas de naturaleza.

Quiero reconocer:

la vegetación local

los espacios públicos

la arquitectura

la ciudad

su ambiente tropical

su gente

La identidad visual debe ser auténticamente cruceña.

19. RESPONSIVE

Mantener una experiencia perfecta en:

Desktop

En móvil:

Hero completo
